# bingo share 页面设计（Share Page Design）

> 版本：v2.2 · 状态：草案（对齐 opencode share 样式参考 + 用户指令；视图集 = 对话/Team/私聊/频道）
> 参考：`opencode-share-reference.md`（sst/opencode share 页面源码提取，用户指定对齐）
> 定位：`bingo share` 子命令导出的自包含 HTML 分享页。零外部依赖、离线可用、内嵌 CSS、打印友好。
> 配套产物：`share-page-template.html`（本文件文末模板的独立副本，**以 .html 为唯一事实源**，改模板时同步回本文）。
> **v2.0 关键变更**：终端暗色 → **浅色文档底**（opencode 对齐）；消息行 → **左装饰列（锚点图标 + 3px 贯穿竖线）+ 内容限宽（sm/md/lg）**；助手消息细边框卡、用户无框；工具两段式；元信息小号大写；消息锚点 + 复制链接。四视图（对话/Team/私聊/频道）与空态恒存在保留不变。

## 0. 设计原则

1. **文档感，不是终端感**：分享页是"一次会话的文档快照"。浅色底、hairline 分隔、留白——读起来像一份排版考究的文档，而不是终端截图。终端血统由等宽代码块与工具行保留。
2. **克制是纪律**：无阴影、无渐变、无气泡堆砌、无卡片堆叠、无装饰动画；语义色只用于状态与强调（绿/红/橙）。
3. **无 JS 核心**：数据由 Rust 端服务端渲染（全量转义），JS 只做四类渐进增强：tab 切换、消息锚点复制链接、代码复制、打印展开。
4. **事实完整**：工具输入 JSON 与结果原样呈现、不截断（PRD A4）——默认折叠，展开即全文。
5. **状态先行**：四视图恒存在，无数据显示英文空态，不 panic 不破坏结构。

## 1. 视觉锚点

| 锚点 | 决策 | 理由 |
|---|---|---|
| 底色 | 暖白 `#FAFAF7`（页面）/ `#FFFFFF`（卡片）/ `#F3F2EF`（结果块） | 文档纸面感；浅色印刷友好 |
| 消息时间线 | 左装饰列（18px 锚点图标 + 3px 贯穿竖线）+ 内容列限宽 | opencode 参考 §2，时间线不靠卡片隔断 |
| 内容限宽 | 三档：sm 480px（工具结果）/ md 640px（正文、思考）/ lg 760px（diff 等宽内容） | 窄列聚焦，长行不糊满全宽 |
| 助手消息 | 1px 细边框卡（橙 tint `#E7C4B2`）+ 4px 圆角 + 0.5rem padding | opencode 参考 §3；blue-high → bingo 品牌橙 |
| 用户消息 | 无框纯文本 | 同上 |
| 工具调用 | 两段式：标题行（工具名 + 目标参数摘要，secondary 色）+ 结果块（`Show result` 可展开） | 参考 §3；不做大 JSON 卡片 |
| 元信息 | 小号大写字母行（`ASSISTANT · CLAUDE-OPUS-4.6 · 08-07 09:12`，secondary） | 参考 §3 step-start |
| 字体 | 无衬线正文 + 等宽代码 | 参考 §1；文档可读性 |
| 强调色 | bingo 品牌橙 `#B05227`（链接/强调，5.15:1）替代 opencode blue-high | 品牌一致性 |

## 2. 色板（浅色文档令牌）

```css
:root {
  /* 表面 */
  --bg:        #FAFAF7;   /* 页面底（暖白） */
  --bg-card:   #FFFFFF;   /* 卡片/代码块底 */
  --bg-subtle: #F3F2EF;   /* 工具结果/状态底 */
  --hairline:        #E5E4DF;   /* 分隔线 */
  --hairline-strong: #D8D7D1;   /* 竖线/强分隔 */

  /* 文本 */
  --text:      #1F2328;   /* 13.5:1 */
  --secondary: #57606A;   /* 6.1:1 元信息/工具标题 */
  --dimmed:    #646D76;   /* 4.6:1 次级正文 */
  --faint:     #8A929B;   /* 仅装饰（锚点图标/虚线） */

  /* 语义 */
  --accent:       #B05227;   /* 品牌橙 5.15:1（链接/强调） */
  --accent-soft:  #D77757;   /* 大图标/装饰（≥3:1 即可的场景） */
  --accent-border:#E7C4B2;   /* 助手卡/思考卡边框（橙 tint） */
  --green: #1A7F37;   /* 成功 5.1:1 */
  --red:   #CF222E;   /* 错误 5.4:1 */
  --gold:  #9A6700;   /* 警告 4.7:1 */
  --info:  #146C7A;   /* 工具/信息 5.8:1 */

  /* 成员色板（子代理/频道 from，浅底下取深档，全部 ≥4.5:1） */
  --hue-0:#0F766E; --hue-1:#4A58C8; --hue-2:#6E40C9;
  --hue-3:#8A6418; --hue-4:#B03A8B; --hue-5:#2F7D32;
}
```

- 成员取色：`idx = hash(name) % 6`，重名顺延；`main`/`assistant` 恒为 `--accent`，`user` 恒为 `--text`。
- 全部颜色走 `var()`；打印只重定义必要令牌。
- 对比度声明：正文 13.5:1、secondary 6.1:1、dimmed 4.6:1、accent 5.15:1、语义色全 ≥4.5:1（数值均已按 WCAG 相对亮度核算，qa 可抽查）。

## 3. 布局

### 3.0 页面骨架（导航沿用 tab 方案，与 dev 现有实现一致）

```
┌────────────────────────────────────────────────────────┐
│ topbar（sticky，白底 + hairline 底边）                  │
│  ▸ bingo · 会话标题      project · model · 时间   [⎙]  │
│  [1]Conversation [2]Team·3 [3]DM·2 [4]Channels·2       │
├────────────────────────────────────────────────────────┤
│ main（max-width 880px 居中，单视图）                    │
│  Conversation：消息时间线（装饰列 + 限宽内容）          │
│  Team：名册行                                          │
│  DM：每子代理折叠线程                                   │
│  Channels：频道块                                      │
├────────────────────────────────────────────────────────┤
│ footer：Generated by bingo share · 版本 · 隐私提示     │
└────────────────────────────────────────────────────────┘
```

- tab 为 `role=tablist`（1–4 快捷键 + hash 直达），JS 只切显示不碰数据；视图面板 `data-view` + `hidden`。
- 无 JS 时默认展示 Conversation 视图，其余面板隐藏（数据已服务端渲染，无脚本注入面）。

### 3.1 消息行结构（对话视图核心）

```
┌──┐  ┌────────────────────────────────────────┐
│🔗│  │ ASSISTANT · CLAUDE-OPUS-4.6 · 08-07    │  ← 元信息行（小号大写 secondary）
│▏│  │ ┌──────────────────────────────────┐    │
│▏│  │ │ 正文（细边框卡：1px 橙 tint 边）   │    │  ← 助手文本
│▏│  │ └──────────────────────────────────┘    │
│▏│  │ ┌ Thinking ─────────────┐               │  ← 思考块（同款卡，可展开）
│▏│  │ └────────────────────────┘               │
│▏│  │ ⏺ Bash · git status --short             │  ← 工具标题行（secondary）
│▏│  │ ▸ Show result ────────────┐              │  ← 结果块（展开出 input/result）
│▏│  │ └──────────────────────────┘             │
│▏│  │                                           │
└──┘  └────────────────────────────────────────┘
  3px 竖线贯穿整条消息（hairline-strong，圆角 1px）
```

- 网格：`.msg { grid-template-columns: 22px 1fr; gap: 14px }`。
- 装饰列 `.dec`：顶部 `.anchor`（18px 链接图标，hover 变橙；点击复制 `当前页 URL + #msg-id`）+ `.line`（3px 竖线 flex:1）。
- 内容列 `.content`：`w-sm/w-md/w-lg` 限宽；底部 1.25rem 间距（消息间靠竖线 + 间距，不用卡片隔断）。
- 每条消息 `id="msg-N"`，锚点可直达。

## 4. 四视图规格

### 4.1 Conversation（对话）——主会话完整记录

- **user**：`.content w-md` > 元信息行 + `.body` 纯文本（无框）。
- **assistant**：`.content w-md` > 元信息行 + `.card`（1px `--accent-border` 细边框 + 4px 圆角 + 0.5rem padding）内含 markdown 正文。
- **thinking**：`.card` 同款独立块（`details.think`，summary = `Thinking` 小号大写 secondary；展开显示全文，浅灰斜体可留白）。
- **工具调用**：`.tool` 两段式——
  - 标题行 `.tool-title`：`⏺` 图标（info 色）+ `.t-name`（secondary，等宽）+ `.t-args`（目标参数摘要：命令/文件路径/pattern，`--faint`）；不展开 input 大 JSON。
  - 结果块 `details.tool-result`：summary = `Show result`（+ 状态 `✓/✗`，绿/红）；展开 = `.t-body`（`input` + `result` 两个 `.t-code`，`pre` 原样不截断）；`w-sm` 限宽。
  - tool_use 与其同 id tool_result 合成一个 `.tool`；缺 result 显示 `running…`。
- **代码块**：`figure.code-block`（`figcaption` 语言标签 + `pre code` + 复制按钮）。
- **图片**：`figure.img-block` + `<img src="data:…">`（仅 data: URI，PRD C3）。

### 4.2 Team（子代理名册）

- 网格行（hairline 分隔，无卡片）：状态标记（`● idle` / `◐ running` / `✗ stopped`，字形 + 颜色双通道，idle=faint、running=info、stopped=red）· name（accent）· def 源（secondary）· 消息数（secondary）· description（dimmed）。
- 空态：`— No team —`。

### 4.3 DM（私聊）——每子代理历史（SendMessage 续话）

- 每代理一个 `<details class="dm-agent">`（原生可折叠）：summary = 状态点（成员色）+ name + state + 条数；展开 = 线程行 `dm-row`（`dm-from` 成员色 + `dm-text` + `dm-time`）。
- user 消息行右对齐弱化（不加粗 + 靠右），主 agent（main）与成员区分靠 from 色。
- 空态：`— No direct messages —`。

### 4.4 Channels（频道）——频道消息流

- 每频道 `.ch-block`（hairline 边框 + 白底）：块头 = `◇ #name`（accent）+ mode 徽标（serial=info / free=periwinkle `#4A58C8`）+ 成员 chips（从 from 去重推导，可选）。
- 消息行：`#0001`（seq 四位补零，faint）· from（成员色）· text；user 消息右对齐。
- 空态：`— No channels —`。

## 5. 动效（全部渐进增强，克制）

| 场景 | 动效 | 参数 | JS? |
|---|---|---|---|
| tab 切换 | 面板淡入 | opacity 120ms | 是（导航） |
| 锚点图标 hover | 变 accent + 链环提示 | 120ms | 否 |
| 复制成功反馈 | 图标短暂变 ✓ | 120ms + 1.6s 复位 | 是（增强） |
| details 展开 | 原生 | — | 否 |
| 打印 | 展开全部 details | beforeprint | 是（增强） |

全局 `prefers-reduced-motion` 关闭全部 transition。无滚动特效、无光标、无入场动画。

## 6. 打印

- 页面本就浅色：`@media print` 白底 + 展开全部 details（beforeprint JS）+ 隐藏 tab/复制/锚点按钮。
- `pre` 与 `details` 头 `break-inside: avoid`；正文允许跨页。

## 7. 可访问性

| 项 | 规格 |
|---|---|
| 对比度 | §2 表全部达标（可抽查 accent 5.15:1、dimmed 4.6:1） |
| 语义 | `header/nav[role=tablist]/main/section[role=tabpanel]/footer`；消息 `article` + `id`；折叠原生 `<details>`；空态文本可读 |
| 键盘 | tab 方向键轮转 + 1–4 快捷键；锚点链接原生可达；焦点环 `outline: 2px solid var(--accent)` |
| 非颜色通道 | 状态字形 + 颜色（✓/✗/●/◐/○）；链接下划线 |
| 其他 | `::selection` 反色；skip link；`lang="en"`；图片 alt 必填；装饰图标 `aria-hidden`；**`aria-hidden` 不得包裹可聚焦元素**——`.line` 竖线装饰 `aria-hidden`，`.anchor` 链接保持可访问（v2.2 修正：原模板把 `aria-hidden` 放在 `.dec` 容器上，会遮蔽其中的可聚焦锚点，读屏不可见但键盘可达，违反 WCAG） |

### 8.2 转义与数据纪律（沿用 PRD C 组 + 现实现）

- 所有动态文本全量转义（`& < > " '`）；工具 JSON 放 `<pre>`（不解析为 HTML）；图片仅 `data:` URI。
- 坏行跳过语义与 `load_messages` 一致；未知块类型跳过不 panic。
- `t-args` 取目标参数摘要（命令/文件路径/pattern 首个值，≤ 60 字符），完整 input 仍存于结果块 `pre`（A4 不截断）。

### 8.3 markdown 输出规范（沿用现实现 + 补充）

段落/标题/列表/引用/行内格式/围栏代码块（`figure.code-block` + `figcaption` + `pre code`）保持；表格样式已内置模板。

(function(){
  'use strict';

  /* ---------- tabs（导航；面板已服务端渲染，JS 只切换显示） ---------- */
  function activateTab(name){
    var panels = document.querySelectorAll('.view');
    for (var i = 0; i < panels.length; i++){
      panels[i].hidden = panels[i].getAttribute('data-view') !== name;
    }
    var tabs = document.querySelectorAll('.tabs button');
    for (var j = 0; j < tabs.length; j++){
      var on = tabs[j].getAttribute('data-tab') === name;
      tabs[j].setAttribute('aria-selected', on ? 'true' : 'false');
      tabs[j].tabIndex = on ? 0 : -1;
    }
    if (history.replaceState) history.replaceState(null, '', '#' + name);
  }
  function bindTabs(){
    var tabs = Array.prototype.slice.call(document.querySelectorAll('.tabs button'));
    tabs.forEach(function(btn){
      btn.addEventListener('click', function(){ activateTab(btn.getAttribute('data-tab')); });
      btn.addEventListener('keydown', function(e){
        var idx = tabs.indexOf(btn);
        var next;
        if (e.key === 'ArrowRight' || e.key === 'ArrowDown'){
          e.preventDefault();
          next = tabs[(idx + 1) % tabs.length];
        } else if (e.key === 'ArrowLeft' || e.key === 'ArrowUp'){
          e.preventDefault();
          next = tabs[(idx - 1 + tabs.length) % tabs.length];
        } else { return; }
        next.focus();
        activateTab(next.getAttribute('data-tab'));
      });
    });
    document.addEventListener('keydown', function(e){
      if (e.altKey || e.ctrlKey || e.metaKey) return;
      var map = { '1': 'conv', '2': 'team', '3': 'dm', '4': 'channel' };
      if (map[e.key]) activateTab(map[e.key]);
    });
    var name = (location.hash || '').replace('#', '');
    if (['conv', 'team', 'dm', 'channel'].indexOf(name) >= 0) activateTab(name);
  }

  /* ---------- 消息锚点：点击复制 URL + #id ---------- */
  function bindAnchors(){
    var anchors = document.querySelectorAll('.dec .anchor');
    for (var i = 0; i < anchors.length; i++){
      anchors[i].addEventListener('click', function(e){
        e.preventDefault();
        var target = this.getAttribute('href');
        var url = location.href.split('#')[0] + target;
        var done = function(ok){
          this.classList.add('copied');
          setTimeout(function(){ this.classList.remove('copied'); }.bind(this), 1600);
        }.bind(this);
        var fallback = function(){
          var ta = document.createElement('textarea');
          ta.value = url;
          ta.style.position = 'fixed';
          ta.style.opacity = '0';
          document.body.appendChild(ta);
          ta.select();
          var ok = false;
          try { ok = document.execCommand('copy'); } catch (e) {}
          document.body.removeChild(ta);
          done(ok);
        };
        if (navigator.clipboard && navigator.clipboard.writeText){
          navigator.clipboard.writeText(url).then(function(){ done(true); }, function(){ fallback(); });
        } else { fallback(); }
      });
    }
  }

      (function(t){
        var pre = t.querySelector('pre');
        if (!pre || t.querySelector('.copy-btn')) return;
        var btn = document.createElement('button');
        btn.type = 'button';
        btn.className = 'copy-btn';
        btn.textContent = 'Copy';
        btn.setAttribute('aria-label', 'Copy code');

          function done(ok){
